# Crossy Road - Minimalist Edition

A ultra-minimalist 2.5D browser game inspired by Crossy Road, built with vanilla JavaScript and HTML5 Canvas.

## 🎮 Play Now

[Play the game here](https://diegosecor.github.io/HW2-Crossy-Road/)

## ✨ Features

- **Pure vanilla JavaScript** - No frameworks, no build steps
- **Isometric 2.5D graphics** - Geometric minimalist aesthetic
- **Procedural generation** - Infinite lanes with roads and rivers
- **Smooth gameplay** - Arrow key controls, camera following
- **GitHub Pages ready** - Single HTML file deployment

## 🎯 How to Play

- **Arrow Keys** - Move your sphere one tile at a time
- **Objective** - Move forward to increase your score
- **Avoid** - Moving obstacles and falling in the river
- **Stay alive** - Jump on logs to cross rivers safely
- **Space** - Restart after game over

## 🚀 Deploy Your Own

1. Fork this repository
2. Go to Settings → Pages
3. Set Source to "main" branch
4. Your game will be live at `https://diegosecor.github.io/HW2-Crossy-Road/`

## 🛠️ Technical Details

- Single `index.html` file with embedded CSS and JavaScript
- HTML5 Canvas 2D rendering with isometric projection
- Procedural lane generation algorithm
- Collision detection for obstacles and water
- Smooth camera interpolation
